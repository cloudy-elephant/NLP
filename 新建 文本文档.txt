调研：
MASCA 框架的全称是 Multi-Agent System with Credit Assessment，
它是 2025 年 7 月发布的一种**多智能体（multi-agent）+ 大语言模型（LLM）**驱动的信贷评估框架。

它的核心思想是：

把信贷审核流程拆分成多个互相协作的“Agent”，每个 Agent 负责一个子任务，通过层级式（hierarchical）协作来完成整个信用评估。
MASCA 框架的关键特点
多角色分工

数据采集 Agent：从内部数据库、征信机构、外部 API 获取申请人的财务与信用数据。

风险评估 Agent：分析申请人的违约概率、风险等级。

收益分析 Agent：预测贷款可能带来的利润、利息收益等。

偏差检查 Agent：检测模型输出是否有偏见（如性别、地域歧视）。

合规审查 Agent：确保决策符合监管法规和银行内部政策。

层级式协作

顶层有一个 决策协调 Agent（Coordinator Agent），负责统筹各个子 Agent 的结果，形成综合的贷款审批建议。

各子 Agent 会并行或按流程协作，并在必要时互相请求数据或分析结果。

LLM + 工具调用

使用 LLM（如 GPT-4、Claude、Qwen 等）进行自然语言理解与推理。

结合外部工具（如 API 调用、数据库查询、风险模型计算），形成 Agentic AI 能力。

可扩展性

可以根据不同银行或金融机构的需求添加新的 Agent（如欺诈检测、文件真实性校验等）。
